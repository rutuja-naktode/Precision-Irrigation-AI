# AI-Based Precision Irrigation Advisory System

A Python-based machine learning project that helps farmers make informed irrigation decisions using soil moisture, crop details, and weather forecasts.

## Features

* Crop and soil selection
* Soil moisture input
* Weather forecast integration
* Machine learning-based irrigation advisory
* Estimated water requirement
* CSV report download

## Technologies Used

* Python
* Streamlit
* Scikit-learn
* Pandas
* Open-Meteo API

## How to Run

1. Install Python.
2. Install dependencies:
   `pip install -r requirements.txt`
3. Run the application:
   `streamlit run app.py`

## Note

This is an educational prototype. Its ML model uses synthetic demonstration data and is not validated for real-world agricultural decisions.
